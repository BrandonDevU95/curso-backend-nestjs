# curso-backend-nestjs
Aprende a construir una API RESTful profesional con NestJS, integrando autenticación, roles de usuario y persistencia de datos con TypeORM y PostgreSQL. Crea funcionalidades avanzadas como generación automática de resúmenes de artículos mediante Inteligencia Artificial. Desarrolla habilidades clave para estructurar, documentar y desplegar.
